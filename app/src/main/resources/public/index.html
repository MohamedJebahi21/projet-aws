Supervision Multi-AZ & Contrôle de Santé ALB

Architecture 3-Tiers Déployée

  • Tier 1 - Présentation : Application Load Balancer (ALB) Multi-AZ exposé sur Internet.
  • Tier 2 - Applicatif : Auto Scaling Group (EC2 t3.micro) en sous-réseaux privés étanches.
  • Tier 3 - Données : Amazon RDS PostgreSQL managé en sous-réseau privé avec sauvegardes.
  • Stockage Objet : Amazon S3 chiffré pour les reçus PDF et artefacts.
